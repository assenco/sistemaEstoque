# Sistema de Gestão de Estoque

## Propósito

O sistema tem como objetivo criar uma base de dados de estoque que permita registrar, listar, editar e excluir itens.

## Aplicação

Lojas físicas, on-line ou híbridas que necessitem de um controle digital de seu estoque.

## Etapas / Versões

### V1.0 — Versão inicial em C

Desenvolvimento inicial do sistema em linguagem C, aplicando operadores, estruturas de controle, arrays e validação de entrada de dados, com toda a lógica concentrada na função `main`.

### V2.0 — Modularização e persistência

Aplicação de structs, funções, modularização do código em arquivos `.c` e `.h`, uso de ponteiros e persistência de dados.

### V3.0 — Versão Web

Desenvolvimento do sistema para a Web, utilizando HTML, CSS e JavaScript, com as mesmas funcionalidades da versão em C, porém em uma interface visual executada no navegador.

Nesta versão está previsto o uso de um banco de dados (Microsoft SQL Server Express) para o armazenamento das informações, mas o momento dessa implementação ainda não foi definido.
